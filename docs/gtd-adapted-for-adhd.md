## Executive Summary

**GTD (Getting Things Done)** is David Allen's influential productivity methodology that teaches how to capture, organize, and execute tasks systematically. For ADHD brains, GTD offers valuable external scaffolding for executive function challenges—but the full system can be overwhelming.

**The Key Insight:** GTD teaches skills that don't come naturally to ADHD brains (prioritization, planning, breaking down tasks), making it potentially powerful—but also requiring significant adaptation.

**This Guide Covers:**
- The core GTD methodology
- Why the full system often fails for ADHD
- Simplified versions that work (including Zen to Done)
- Practical implementation for various tools

## Understanding GTD

### The Five Pillars of GTD

David Allen's system centers on five core steps:

#### 1. Capture
**Get everything out of your head.**

- Collect all tasks, ideas, and commitments into a trusted "inbox"
- Use any tool: notebook, app, voice memo, email drafts
- Don't organize yet—just capture

**Why this matters for ADHD:**
- Reduces cognitive load (working memory struggles)
- Prevents the mental loop of "don't forget this"
- Externalizes what your brain can't reliably hold

#### 2. Clarify
**Process what each item means.**

For each item, ask:
- Is it actionable?
- If not: Trash it, incubate it (someday/maybe), or file as reference
- If yes: What's the next physical action?
- Can it be done in 2 minutes or less? Do it now
- Should it be delegated? Delegate it
- Does it need scheduling? Put it on calendar

**The 2-Minute Rule:**
If something takes less than 2 minutes, do it immediately rather than tracking it.

#### 3. Organize
**Put things where they belong.**

GTD uses several lists:
- **Next Actions:** Single, actionable tasks (not projects)
- **Projects:** Any outcome requiring multiple actions
- **Waiting For:** Items delegated or pending from others
- **Someday/Maybe:** Ideas for the future
- **Calendar:** Time-specific commitments only

**Contexts (Optional):**
Traditional GTD uses contexts like @home, @computer, @phone, @errands to filter tasks by location/tool.

#### 4. Reflect
**Review your system regularly.**

- **Daily Review:** Check calendar and next actions
- **Weekly Review:** Process inbox, review all lists, update projects

#### 5. Engage
**Do the work.**

Choose actions based on:
- Context (where you are, tools available)
- Time available
- Energy level
- Priority

## Why GTD Can Be Problematic for ADHD

### The Overwhelm Problem

**Too many changes at once:**
The main reason people fall off GTD is that it requires multiple habit changes attempted simultaneously. For ADHD brains, this is a recipe for system abandonment.

**Too many lists:**
Managing separate lists for Next Actions, Projects, Waiting For, Someday/Maybe, plus context tags can create more cognitive overhead than it solves.

**Too unstructured:**
GTD's flexible "choose what to do in the moment" approach can be paralyzing for ADHD brains that struggle with:
- Decision-making (executive dysfunction)
- Prioritization (everything feels urgent or nothing does)
- Time estimation (time blindness)

### Executive Function Gaps

GTD assumes you can:
- Break projects into clear next actions
- Accurately estimate time for tasks
- Make consistent prioritization decisions
- Maintain regular review habits
- Resist the pull of the "someday/maybe" black hole

**ADHD Reality:**
Executive dysfunction means these skills don't function reliably—exactly why external systems help, but also why complex systems fail.

### The Perfection Trap

GTD can trigger ADHD perfectionism:
- "I need to capture EVERYTHING"
- "My system needs to be perfect before I can start"
- "I missed a weekly review, so the whole thing is ruined"

This all-or-nothing thinking leads to system abandonment.

## ADHD-Friendly Adaptations

### Start Small: The Gradual Approach

**Don't implement the full system at once.**

**Week 1-2:** Just capture
- Pick ONE inbox (paper notebook, phone app, whatever)
- Practice getting things out of your head
- Don't organize yet

**Week 3-4:** Add basic clarifying
- Once daily, look at inbox
- Ask: "Is this actually something I need to do?"
- Delete/do 2-minute tasks/or move to simple task list

**Week 5+:** Add structure gradually
- Introduce project list (things with multiple steps)
- Start basic weekly review
- Add additional lists only when needed

### Simplify the Lists

**Minimal GTD Setup:**

| Instead of... | Use... |
|---------------|--------|
| Multiple context lists | One "Next Actions" list |
| Detailed project plans | Simple project names with "next action" noted |
| Someday/Maybe list | Monthly review or delete |
| Waiting For list | Add "@waiting" tag to main list |

**The 3-List System:**
1. **Inbox:** Everything goes here first
2. **Actions:** Things you can actually do
3. **Projects:** Multi-step outcomes (just the names)

### Simplify Decisions: The 3 D's

When processing inbox, you only need three choices:

1. **Delete:** Not actually needed? Trash it
2. **Do:** Takes 2 minutes or less? Do it now
3. **Delegate:** Someone else should handle? Send it

Everything else goes to your Actions list.

### Add Structure for ADHD Brains

**Daily Highlight Method:**
Each morning, choose ONE task that will make the day successful. Do that first.

**Time-Boxing Reviews:**
Instead of open-ended weekly reviews, set a timer:
- 5-minute inbox processing (daily)
- 15-minute weekly review (no more)

**Energy Tags Instead of Contexts:**
Replace @home/@computer with:
- High Energy tasks
- Low Energy tasks
- Quick Wins (dopamine boosters)

### The Weekly Review (Simplified)

Traditional GTD weekly review can take hours. ADHD version:

**15-Minute Weekly Review:**

1. **Empty inbox** (5 min)
   - Delete what you can
   - Do 2-minute tasks
   - Move rest to actions list

2. **Scan actions list** (5 min)
   - Delete anything no longer relevant
   - Star 3-5 items for next week
   - Note any blocked items

3. **Check projects** (5 min)
   - Does each project have a clear next action?
   - Any projects to delete or pause?

**That's it.** Don't aim for perfect—aim for "good enough to keep going."

## Zen to Done (ZTD): The Simplified Alternative

### What is ZTD?

**Zen to Done** was created by Leo Babauta (Zen Habits) as a response to GTD's complexity. It takes the best parts of GTD and makes them:
- Habit-focused (one change at a time)
- Action-oriented (emphasis on doing, not planning)
- Simpler (fewer lists, less overhead)

### Why ZTD Works Better for ADHD

| GTD | ZTD |
|-----|-----|
| Many habits at once | One habit at a time |
| Complex list system | Simple, minimal lists |
| Flexible "do what feels right" | Structured daily planning |
| Perfectionist tendencies | "Good enough" philosophy |
| Focus on capturing everything | Focus on doing what matters |

### The 10 ZTD Habits (Full System)

1. **Collect:** Capture everything in inbox
2. **Process:** Make quick decisions on items
3. **Plan:** Set MITs (Most Important Tasks) daily
4. **Do:** Focus on one task at a time
5. **Simple trusted system:** Keep it minimal
6. **Organize:** Everything has a home
7. **Review:** Weekly review
8. **Simplify:** Reduce goals and tasks
9. **Routine:** Set daily/weekly routines
10. **Find your passion:** Pursue meaningful work

### Minimal ZTD (The ADHD-Friendly Version)

**You only need 4 habits:**

#### Habit 1: Collect
- Choose ONE capture tool
- Get thoughts out of your head immediately
- Don't organize—just capture

#### Habit 2: Process
- Review inbox once daily
- Make quick decisions: delete, do, or defer
- Never more than 10 minutes

#### Habit 3: Plan (MITs)
- Each morning, choose 1-3 Most Important Tasks
- Write them where you'll see them
- Do these before anything else

#### Habit 4: Do (Focus)
- Work on ONE task at a time
- Eliminate distractions during focus time
- Don't multitask

### Implementing One Habit at a Time

**The 30-Day Rule:**
Don't add a new habit until the current one feels automatic (typically 30 days).

**Suggested Order for ADHD:**
1. **Month 1:** Collect (just capture everything)
2. **Month 2:** Process (daily inbox review)
3. **Month 3:** Plan (daily MITs)
4. **Month 4:** Do (single-tasking blocks)

**Why this works:**
- Builds on success, not overwhelm
- Each habit reinforces the previous
- Failure at one stage doesn't collapse everything
- Creates sustainable change

### 1. Spreadsheet Implementation (Google Sheets/Excel)

#### Sheet 1: Inbox

```
A              B              C
Item           Date Added     Processed?
────────────   ────────────   ──────────
Call dentist   1/25/26        ✓
Project idea   1/25/26
Email boss     1/25/26        ✓
```

**Setup:**
- Column A: Raw capture (anything goes)
- Column B: Auto-date when added
- Column C: Checkbox when processed

#### Sheet 2: Actions

```
A              B        C          D           E
Task           Energy   Project    Due         Done
────────────   ──────   ─────────  ──────────  ────
Draft report   High     Q1 Plan    1/30/26
Reply emails   Low                             ✓
Buy supplies   Medium   Home
```

**Properties:**
- Energy: Dropdown (High/Medium/Low)
- Project: Optional link
- Due: Only if time-specific
- Done: Checkbox

#### Sheet 3: Projects

```
A              B              C                D
Project        Status         Next Action      Progress
────────────   ────────────   ──────────────   ────────
Q1 Planning    Active         Draft outline    30%

```

#### Sheet 4: Daily Dashboard

```
TODAY: January 25, 2026

┌─────────────────────────────────────┐
│  MITs (Most Important Tasks)        │
│  ─────────────────────────────────  │
│  1. [ ] ________________________    │

```

**Formulas:**
- `FILTER` to show tasks matching current energy level
- `COUNTIF` for project progress calculation
- Conditional formatting: overdue = red, completed = green

### 2. Notion Template Implementation

#### Database 1: Inbox

**Properties:**
- Name (title)
- Created (date, auto)
- Processed (checkbox)
- Notes (text)

**Views:**
- Unprocessed (filter: Processed = false)
- All Items (table)

#### Database 2: Actions

**Properties:**
- Task (title)
- Status (select: To Do / In Progress / Done)
- Energy (select: High / Medium / Low)
- Project (relation to Projects)
- Due Date (date)
- Is MIT (checkbox)

**Views:**
- Today's MITs (filter: Is MIT = true, Status ≠ Done)
- By Energy (board, grouped by Energy)
- All Tasks (table)
- Quick Wins (filter: Energy = Low, estimated time < 15 min)

#### Database 3: Projects

**Properties:**
- Project Name (title)
- Status (select: Active / Paused / Complete)
- Next Action (text)
- Related Tasks (relation to Actions)
- Progress (formula: % of related tasks done)

**Views:**
- Active Projects (filter: Status = Active)
- All Projects (table)

## Key Takeaways

### The Core ADHD-GTD Principles

1. **Start with capture only** — Build one habit before adding more
2. **Simplify ruthlessly** — Fewer lists = less overwhelm
3. **Daily MITs over endless lists** — Focus on 1-3 things that matter
4. **Energy-based, not context-based** — Match tasks to your capacity
5. **Good enough beats perfect** — A messy system you use beats a perfect one you don't
6. **Time-box your processing** — 5 minutes daily, 15 minutes weekly
7. **Delete liberally** — Most "someday" items never happen

### GTD vs. ZTD for ADHD

| Choose GTD If... | Choose ZTD If... |
|------------------|------------------|
| You like detailed systems | You prefer minimal structure |
| You have many complex projects | You need habit-building focus |
| You've used GTD before | You're new to productivity systems |
| You have support (coach, etc.) | You're self-implementing |
| You can handle weekly reviews | Reviews feel overwhelming |

### The Minimum Viable System

If everything else fails, do just this:

1. **One inbox** (capture tool of choice)
2. **One action list** (simple task list)
3. **One daily question:** "What's the ONE thing that would make today successful?"

**That's it.** Add complexity only when simplicity stops working.

### Common Mistakes to Avoid

1. **Trying to capture everything at once** — Your inbox will never be empty, and that's okay
2. **Too many lists/categories** — Start with 2-3 maximum
3. **Skipping the 2-minute rule** — This is gold for ADHD momentum
4. **Rigid weekly reviews** — Flexible 15-minute check-ins work better
5. **Perfectionism** — The system serves you, not the other way around
