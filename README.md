# NextPlan

A knowledge base for ADHD-friendly productivity systems, methodologies, and implementation guides.

## Overview

NextPlan documents productivity frameworks designed for neurodivergent brains—systems that work **with** how your brain actually functions rather than fighting against it.

### Core Philosophy

- **Energy management over time management**
- **Micro-commitments over overwhelming goals**
- **Progress over perfection**
- **Adaptation over rigid discipline**

## Key Concepts

### The Kaizen Method

Based on Ruri Ohama's approach, the Kaizen system uses three daily practices (5 minutes total):

1. **Brain Dump** — Clear mental clutter
2. **Daily Highlight** — One meaningful task for the day
3. **Micro-Commitment** — 2-minute action toward a habit

### Why Traditional Productivity Fails for ADHD

ADHD brains operate with an **interest-based nervous system** (not importance-based). Motivation requires:

- **P**assion & Play
- **I**nterest
- **N**ovelty
- **C**ompetition/Challenge
- **H**urry (Urgency)
